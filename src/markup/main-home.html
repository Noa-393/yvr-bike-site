FAQs

Everything you need to know about yvr.bike

What are the directories?

They are a single app for Vancouver cyclists to find shops, routes, events, clubs and more. No more hunting across ten different websites and social media profiles. Everything you need is in one place.

Is it free to use?

Yes. I built this app because I wanted to contribute to the local Vancouver cycling community, so it is free for everyone to use, without ads, affiliate links or sponsors. If you want to contribute towards development / hosting costs, feel free to buy me a virtual coffee. If we know each other IRL, you know how much I like my coffee...

Can I add a club event, ride, retailer, route, etc?

You can not add a listing yourself, but you can submit anything you want to see featured and I will add it myself. Use this link for submisions. Submitting listings help me make sure everything is up to date and help build the community.

Do I need to create an account?

No, you don't need to create an account, but you can if you want a more personalized experience (totally optional)

How often are the directories updated?

I update listings regularly as shops, events, and routes change. If you spot something outdated, let me know and I will fix it.
